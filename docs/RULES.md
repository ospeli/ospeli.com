# Ospeli ground rules

1. **Synthetic data only.** Never use, paste, upload or derive from any real hospital's records, exports, chat logs, layouts, staff names or figures. The demo hospital ("Example General Hospital") is fictional. Field knowledge enters the product only as general patterns.
2. **People decide, Ospeli suggests.** No allocation, report or clinical draft is issued without a named person's action, and every suggestion is logged with its inputs and the action taken.
3. **Measure flows, never people.** Beds, queues and handoffs are measured by role; no named individual is timed or ranked.
4. **Patient data stays in the hospital.** On-premise first; nothing identifiable leaves a site without written approval for that flow.
5. **Every AI feature has an off switch,** per hospital and per ward, and an evaluation step before it ships.
6. **Report value as patients served and time saved,** never as headcount cut.
